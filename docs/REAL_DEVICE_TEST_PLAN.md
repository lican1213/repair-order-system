## 1. 客户报修测试

**操作步骤：**
1. 扫码或访问 `/repair`
2. 填写完整报修表单
3. 提交

**检查点：**
- [ ] 表单能正常加载
- [ ] 所有必填字段有校验提示
- [ ] 提交成功后显示成功页面
- [ ] 显示预约时间和工单号

---

## 2. 图片上传测试

**操作步骤：**
1. 在报修表单中点击"上传图片"
2. 选择手机相册中的图片
3. 上传 1-3 张图片

**检查点：**
- [ ] 能调起手机相册
- [ ] 图片能正常上传
- [ ] 上传后有预览
- [ ] 超过 3 张有提示
- [ ] 超过 5MB 有提示

---

## 3. 家电类型"其他"测试

**操作步骤：**
1. 选择家电类型为"其他"
2. 观察是否出现输入框
3. 输入自定义家电名称
4. 提交

**检查点：**
- [ ] 选择"其他"后出现输入框
- [ ] 输入框有 placeholder 提示
- [ ] 能正常提交
- [ ] 后台能看到自定义家电名称

---

## 4. 手机号校验测试

**操作步骤：**
1. 输入非 11 位手机号
2. 输入非 1 开头的号码
3. 输入正确的 11 位手机号

**检查点：**
- [ ] 非 11 位显示错误提示
- [ ] 非 1 开头显示错误提示
- [ ] 正确号码无错误提示
- [ ] 错误提示是即时的（不等提交）

---

## 5. 日期和时间段测试

1. 选择过去日期

3. 选择未来日期
4. 选择时间段

**检查点：**
- [ ] 过去日期有错误提示
- [ ] 今天可选
- [ ] 未来日期可选
- [ ] 时间段能正常选择
- [ ] 日期+时间段组合有效
